# Reports

**Source files:** `src/reports/`

---

## Overview

The reports module defines all simulation outputs. Each report is written to a CSV file at a configured time or event. Reports are opt-in: setting `write: false` (or omitting a report from the configuration) disables it without affecting the simulation.

---

## Report configuration

Each report is controlled by a `ReportParams` block in the configuration:

| Field | Description |
|---|---|
| `write` | `true` to enable the report; `false` to skip |
| `filename` | Output file name (required when `write: true`) |
| `period` | For periodic reports: interval between writes (in days) |
| `trigger` | For event-driven reports: what event causes a write |

### Report triggers

| Trigger type | Description |
|---|---|
| `Time { time }` | Write once at a specific simulation time |
| `Date { date }` | Write once on a specific calendar date |
| `Shutdown` | Write at the end of the simulation |
| `SurveillanceCampaign { delay }` | Write a specified number of days after the surveillance campaign starts |

---

## Available reports

### Transmission chain report (`transmission_report.rs`)

**Trigger:** Shutdown
**Output:** One row per person who was part of a transmission chain.

| Column | Description |
|---|---|
| `target_id` | Unique ID of the infected person |
| `infector_id` | ID of their infector (absent for index cases) |
| `infection_time` | Time (days) of infection |
| `symptom_onset_time` | Time of symptom onset (absent if person never became symptomatic) |
| `infection_date` | Calendar date of infection |
| `symptom_onset_date` | Calendar date of symptom onset |

This is the most detailed output: a complete linelist of the simulated epidemic. It can be used to reconstruct the full transmission tree.

---

### Prevalence report (`prevalence_report.rs`)

**Trigger:** Periodic (configurable interval) or Shutdown
**Output:** One row per unique combination of person properties at each reporting time.

| Column | Description |
|---|---|
| `t` | Simulation time |
| `date` | Calendar date |
| `infection_status` | `Presymptomatic`, `Symptomatic`, `Removed`, `Susceptible`, `Vaccinated` |
| `alive` | `true` / `false` |
| `generation` | Epidemic generation (0 for index cases) |
| `case_status` | `None`, `Suspected`, `Confirmed` |
| `detection_status` | `Detected`, `Undetected` |
| `treatment_location` | `None`, `Quarantine`, `Clinic`, `EbolaTreatmentUnit` |
| `count` | Number of persons with this combination of properties |

This is a cross-sectional snapshot of the simulated population, useful for tracking epidemic curves and intervention states over time.

---

### Confirmation incidence report (`confirmation_incidence_report.rs`)

**Trigger:** Periodic or Shutdown
**Output:** One row per `CaseStatus` value per reporting period.

| Column | Description |
|---|---|
| `t_upper` | Upper bound of the reporting period (simulation time) |
| `date` | Calendar date |
| `case_status` | `None`, `Suspected`, `Confirmed` |
| `count` | New cases reaching this status in this period |
| `with_confirmed_index` | Subset of `count` whose infector was already confirmed at the time of their confirmation |

The `with_confirmed_index` column tracks the fraction of new confirmed cases arising from known chains of transmission — a key surveillance performance indicator.

---

### Symptom onset report (`symptom_onset_report.rs`)

**Trigger:** Periodic or Shutdown
**Output:** Daily or periodic count of symptom onsets.

| Column | Description |
|---|---|
| `t` | Simulation time |
| `date` | Calendar date |
| `count` | Number of persons with symptom onset during this period |

This corresponds to the epidemic incidence curve as reported by symptom onset date.

---

### Rₜ and offspring distribution report (`rt_report.rs`)

**Trigger:** Shutdown
**Output:** Two linked reports.

#### Offspring report

One row per infected person:

| Column | Description |
|---|---|
| `infector_id` | ID of the infector |
| `infection_time` | Simulation time |
| `infection_date` | Calendar date |
| `offspring_count` | Number of secondary cases generated by this person |

#### Growth rate report (Rₜ)

One row per calendar date of infection, aggregating the offspring report:

| Column | Description |
|---|---|
| `infection_date` | Calendar date |
| `infection_count` | Number of persons infected on this date |
| `total_offspring` | Total secondary cases produced by persons infected on this date |
| `avg_onward_infections` | `total_offspring / infection_count` — empirical Rₜ estimate |

The `avg_onward_infections` column provides the **realized Rₜ** for each infection cohort: the average number of secondary cases produced by individuals infected on a given day. This is a retrospective measure; it will be incomplete for recent cohorts whose secondary infections have not yet occurred at simulation end.
